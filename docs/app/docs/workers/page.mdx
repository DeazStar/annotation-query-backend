# Workers

The worker subsystem handles all asynchronous graph query execution using Celery. It runs as a separate process pool, keeping the HTTP layer responsive while expensive graph traversals execute in the background.

## Components

- **Celery app** (`app/workers/celery_app.py`) — creates the Celery application, configures Redis broker and result backend.
- **Task handler** (`app/workers/task_handler.py`) — defines Celery task functions and Redis state management utilities.
- **Redis** — serves as broker (task queue), result backend, and pub-sub event channel.
