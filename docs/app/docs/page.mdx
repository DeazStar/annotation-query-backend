# Annotation Query Backend

This handbook documents the Rejuve Bio annotation-query-backend as an engineering system.

## What this site is for

- Give new contributors a fast path into the codebase.
- Capture architecture and runtime decisions that are easy to lose over time.
- Provide one internal place for setup, system behavior, and reference material.

## Source of truth

The handbook documents the upstream repository at `rejuve-bio/annotation-query-backend` (main branch). Current runtime behavior is the source of truth. Where README text or comments drift from the implementation, the code wins.

The current runtime is **FastAPI + Celery + Redis + MongoDB + Socket.IO**. Some README/setup text still references Flask-era commands or assumptions — behavior should be inferred from `app/main.py`, `app/workers/*`, and `app/api/*`.
