# Annotation Storage

## Where it lives

**File:** `app/persistence/annotation_storage_service.py` — `AnnotationStorageService` class

## What it does

Provides static methods for creating, reading, updating, and deleting annotation documents in MongoDB.

## Key operations

### `save(annotation)`

Creates a new annotation document from a dict of fields. Returns the MongoDB document ID.

### `get(user_id)`

Returns the most recent annotation for a user.

### `get_all(user_id, page_number)`

Returns paginated annotations (10 per page, sorted by `_id` descending). Includes annotations where the user is either the owner or a participant.

### `get_by_id(id)`

Fetches a single annotation by its MongoDB ID.

### `update(id, data)`

Updates annotation fields with `$set`.

### `complete_if_pending(id, data)`

Conditional update — only applies when status is still `PENDING`. Used to prevent race conditions when multiple concurrent requests try to complete the same task.

### `get_by_fingerprint(fingerprint)`

Looks up a cached query result by fingerprint. Only returns results where `status == "COMPLETE"`.

### `delete(id)` / `delete_many_by_id(ids)`

Deletes one or more annotation records.

### `add_participant(id, user_id)`

Adds a user to the `participant_user_ids` array (used by the sharing system).

## Status lifecycle

```
PENDING → PROCESSING → COMPLETE
                      → FAILED
                      → CANCELLED
```

The `complete_if_pending` method is critical for ensuring correct status transitions.
