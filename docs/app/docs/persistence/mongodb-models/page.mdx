# MongoDB Models

## pymongoose ODM

The system uses `pymongoose` (version 1.3.8) as its MongoDB ODM. Models are defined as Python classes that extend a base model class, with schema fields mapped to MongoDB document fields.

## Model definitions (`app/models/`)

### `Annotation`

**File:** `app/models/annotation.py`

Stores query history and results for each user.

| Field | Type | Description |
|-------|------|-------------|
| `user_id` | string | Owner of the annotation |
| `request` | object | Original query request parameters |
| `query` | string | Generated query string |
| `title` | string | Auto-generated title (via LLM) |
| `summary` | string | LLM-generated summary |
| `question` | string | Optional question context |
| `answer` | string | Optional answer |
| `node_count` | integer | Number of nodes in result |
| `edge_count` | integer | Number of edges in result |
| `node_types` | array | Types of nodes returned |
| `node_count_by_label` | object | Per-type node counts |
| `edge_count_by_label` | object | Per-type edge counts |
| `status` | string | PENDING, PROCESSING, COMPLETE, FAILED, CANCELLED |
| `species` | string | `human` or `fly` |
| `data_source` | string | Data source filter used |
| `query_fingerprint` | string | Normalized query fingerprint for caching |
| `participant_user_ids` | array | Users this annotation is shared with |

### `User`

**File:** `app/models/user.py`

Stores user preferences.

| Field | Type | Description |
|-------|------|-------------|
| `user_id` | string | Unique user identifier (from JWT) |
| `data_source` | string | Selected data source preference |
| `species` | string | Selected species (`human` or `fly`) |

### `SharedAnnotation`

**File:** `app/models/shared_annotation.py`

Records annotation sharing between users.

| Field | Type | Description |
|-------|------|-------------|
| `user_id` | string | Owner who shared the annotation |
| `annotation_id` | string | The shared annotation's ID |
| `token` | string | Unique token for link-based access |
| `share_type` | string | `token` or `user` |
| `recipient_user_id` | string | Target user (for user-type shares) |
| `role` | string | `viewer`, `editor`, or `owner` |

## Database initialization

**File:** `db.py`

```python
from pymongoose import mongo

def mongo_init():
    mongo.connect(os.getenv('MONGO_URI'))
```

Called at startup from `app/main.py` (FastAPI) or `app/__init__.py` (Flask).
