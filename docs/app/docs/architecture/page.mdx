# Architecture

The annotation-query-backend is a multi-layer system:

- **FastAPI** application serving HTTP and WebSocket endpoints
- **Celery** workers executing long-running graph queries asynchronously
- **Redis** providing task broker, result backend, and pub-sub event bridge
- **MongoDB** persisting annotations, user preferences, and shared annotations
- **Socket.IO** delivering realtime task progress to frontend clients
- **Backend abstraction** supporting Cypher (Neo4j), MeTTa, and MORK CLI engines
