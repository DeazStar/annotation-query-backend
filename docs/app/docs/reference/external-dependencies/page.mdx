# External Dependencies

## Runtime services

| Service | Purpose | Required |
|---------|---------|----------|
| Redis | Task broker, state management, pub-sub event bridge | Yes |
| MongoDB | Persistent storage for annotations, users, shares | Yes |
| Neo4j | Cypher query backend (when `type: cypher`) | Conditional |
| MORK CLI | Production graph backend (when `type: mork_cli`) | Conditional |
| Docker | MORK CLI container runtime | Conditional |

## Optional services

| Service | Purpose |
|---------|---------|
| Elasticsearch | Log indexing and search |
| Sentry | Error tracking and performance monitoring |
| SMTP server | Email notifications for annotation sharing |
| OpenAI API | LLM-based title generation and graph summarization |
| Gemini API | Alternative LLM provider |
