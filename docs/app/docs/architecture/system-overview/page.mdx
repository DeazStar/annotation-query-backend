## Component summary

| Component | Role | Key file |
|-----------|------|----------|
| FastAPI app | HTTP server, lifespan, router | `app/main.py` |
| API router | Route prefixes and endpoint groups | `app/api/api_v1/api.py` |
| Socket.IO server | Realtime event push to clients | `app/socketio/server.py` |
| Redis listener | Lifespan task bridging pub/sub → Socket.IO | `app/main.py` (lifespan) |
| Celery app | Task definitions and worker pool | `app/workers/celery_app.py` |
| Task handler | Celery task implementations | `app/workers/task_handler.py` |
| Schema manager | Loads and serves graph schema | `app/services/schema_data.py` |
| Backend generators | Backend-specific query building | `app/services/*_generator.py` |
| Persistence | MongoDB CRUD via pymongoose | `app/persistence/*` |

## Key architectural decisions

- **FastAPI over Flask** — migrated for async support, better performance, automatic OpenAPI docs.
- **Celery for async tasks** — long graph queries run in worker processes, keeping the HTTP layer responsive.
- **Redis pub/sub bridge** — Celery tasks publish progress events to Redis; the FastAPI lifespan listener forwards them to Socket.IO rooms.
- **Config-driven backend selection** — `config.yaml` determines which graph engine is active at startup; no code changes needed to swap.
- **MORK CLI recommended for production** — wraps the compiled MORK binary in Docker, providing the fastest query performance and largest data handling.
