# Data Sources

The system supports three graph query backends. Each implements the same interface but uses a different engine and data format.

## Pages in this section

- [Cypher Backend](/docs/data-sources/cypher-backend) — Neo4j graph database
- [MeTTa Backend](/docs/data-sources/metta-backend) — hyperon MeTTa runtime
- [MORK CLI Backend](/docs/data-sources/mork-cli-backend) — compiled C++ binary via Docker
- [Schema Management](/docs/data-sources/schema-management) — YAML-driven schema config
- [Graph Assets and Data Dirs](/docs/data-sources/graph-assets-and-data-dirs) — data files and directories
